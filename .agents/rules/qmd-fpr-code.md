### 1.1. 💎 QC-RU-FPR-CODE-KEY
<span style="color:#15803d; font-weight:700;">Thuộc tính 💍 code Mã Kỹ Thuật Độc Bản Cô Đọng Về Một Điểm</span>

🪪 **Tên**: Thuộc tính 💍 code Mã Kỹ Thuật  
📝 **Nội dung**: Tất cả tệp Markdown **BẮT BUỘC** có thuộc tính `💍 code:` trong khối YAML Header:
1. **Bắt buộc là Mã Code Kỹ thuật**: Giá trị `💍 code:` **BẮT BUỘC LÀ MÃ CODE KỸ THUẬT** dạng UPPERCASE / Kebab-Case (Ví dụ: `GS-HH-KQ-XB`, `QC-FBD-APC`, `QC-SKILL-FMT`).
2. **Triết lý Chiếc Nhẫn `💍`**: Chiếc Nhẫn Kim Cương cô đọng toàn bộ thực thể tài liệu về một điểm mã định danh độc bản duy nhất.
