### 1.1. 💎 QC-RU-FPR-TYPE-KEY
<span style="color:#15803d; font-weight:700;">Thuộc tính 🔰 type Với Emoji Phù Hiệu Phân Loại & Mã Loại Tệp Standard</span>

🪪 **Tên**: Thuộc tính 🔰 type Phân loại Tệp  
📝 **Nội dung**: Tất cả tệp Markdown **BẮT BUỘC** có thuộc tính `🔰 type:` (Phù hiệu phân loại) ở đầu khối YAML Header. Giá trị phân loại tiêu chuẩn gồm 6 loại:
- `🔰 type: 📖 AD-SP` (Tệp Đặc tả Yêu cầu Nghiệp vụ - Specification)
- `🔰 type: 💡 AI-SL` (Tệp Thiết kế Phương án Kỹ thuật - Solution)
- `🔰 type: 🧪 AI-TC` (Tệp Kịch bản Kiểm thử & Đối soát - Test Cases)
- `🔰 type: 📜 AI-PL` (Tệp Kế hoạch & Lộ trình Thực thi - Plan)
- `🔰 type: 🧰 AI-SKILL` (Tệp Kỹ năng Hướng dẫn Hệ thống - Skill)
- `🔰 type: 🛡️ AI-RULE` (Tệp Quy tắc & Tiêu chuẩn Quản trị - Rule)
